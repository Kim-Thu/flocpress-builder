A modern Page Builder built with SOLID principles, OOP architecture, and Service Container.

== Description ==
Flocpress Builder is a clean, extensible page builder following SOLID principles.

== Installation ==

1. Upload `flocpress-builder` folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Edit any page and enable "Flocpress Builder"
